分析完成（文档 v2.0 §24 已落盘——这是个大版本，因为它改变了知识块的基本盘）。直接回答：可以抛弃 LoRA，而且有一条 2024–2026 年逐渐成熟的技术线正好补上它的位置。核心洞察是：我们从来不需要 LoRA 的训练，只需要它的效果——而那个效果，推理本身就能产生。

一、理论统一：持久化的上下文 = 冻结的隐式 LoRA

ICL=低秩权重更新这篇论文（2507.16003，已更新到 v4 ）是整个方案的理论地基：带上下文的前向计算，在数学上等价于"无上下文前向 + 一个代表该上下文的最小低秩 MLP 更新"。这句话反过来读就是答案：

> 模型每推理一次，就已经做了一次"隐式 LoRA 微调"——只不过这次微调是临时的、算完就扔。我们要做的不是再训练一个 LoRA，而是把这次隐式微调的内部表示（KV / 状态 / 激活向量）存档下来。

所以"模型经过重复推理形成记忆，再动态调用"在数学上完全成立：记忆块 = 隐式低秩更新的三种存档格式。

二、替代 LoRA 全部职能的三类零梯度块

1. 事实/经历 → KV 块。 经验前向一次即完成编码（这就是"推理即总结"）；存储侧有两个新的免训练优化：Expected Attention（估计每个 token 对未来 query 的价值，免训练修剪 KV 高达 60% ）+ Q4 量化（边缘实测 TTFT 降 136 倍、质量噪声级 ）。

2. 技能/行为 → ICV / Function Vector（这是本轮最重要的发现）。 ICV（ICML 2024 ）：把 demonstrations 前向一遍，从激活中提取任务向量，之后推理时用它平移隐状态即可——在安全、风格迁移、角色扮演、格式化任务上优于标准 ICL 也优于微调，支持幅度调节和向量算术组合（两个技能向量相加 = 组合技能），而且把示例从 prompt 里彻底移除。Function Vector（Todd et al.）同族：把演示压缩成单个激活向量就能复现函数行为，无需微调。更新一点的 DeCoVec（2604.11129 ）把向量做在解码空间（Δz，改 logits 分布）——是现有任务向量里侵入性最低的形态。这正好回答你"直觉 + 可预测出的知识"：技能向量就是"怎么思考的直觉"，KV 块就是"知道什么的事实"。

3. 关联存储 → Hopfield 追加式记忆库（W-Mem）。 现代 Hopfield 网络与注意力在数学上等价 ，支持一次性 Hebbian 存储（模式直接入库，无训练）；且有工作证明模仿齿状回编码后再存储效果更好 ——与我们 DG 稀疏 key 的设计严丝合缝。

4. 调制/风格 → steering 向量（对比激活均值差，一次加法）。

三、"重复推理形成记忆"的四种累积机制（全部无梯度）

1. 平均化：同一技能多次推理的激活取均值，向量自然收敛（ICV/FV 的构造原理）；
2. Hebbian 路径强化：共激活边"走过且验证"则增强（Kairos 验证门控）——路径块自我强化；
3. delta 累积：记忆层 delta 规则天然支持"同 key 重复写 = 强化、异 key 写入 = 新关联"；
4. 吸引子深化：Hopfield 视角下，重复存取同一模式加深其吸引盆——"用进废退"第一次有了数学形式。

四、上下文开支核算与诚实边界

载体	上下文开支	
ICV / steering / DeCoVec 向量	零（一次加法/一次 logits 平移）	
Hopfield 记忆层	零（参数化查询，不占上下文）	
KV 块	小（CSA 压缩 + 60% 修剪 + Q4 后，非零但可控）	

两条必须诚实标注的边界：① steering/ICV 类向量对事实回忆和复杂推理无效甚至起反作用（2026 年实践指南的明确教训 ）——所以"知道什么"必须走 KV 块和路径块，向量只管"怎么思考"；② 需要改变多层计算图的深度程序性技能，仍可能超出零梯度载体的容量——所以睡眠期 LoRA 蒸馏降级保留为可选的深度固化通道（离线、非必需），彻底退出关键路径。

全程：无反向传播、无优化器、无重训、无合并、上下文开支≈零。LoRA 从"记忆的载体"退役为"记忆的勋章"——只有当某段经验被反复使用、证明值得永久改变计算图时，才在睡眠时被追授。 这和你最初"让模型形成直觉"的表述完全一致了。

分析完成（文档 v2.2 §26 已落盘）。你的观察这次得到了一份"官方计分卡"级别的验证——P-RAG v2 的系统对比研究把两条通路的优劣逐项量化过了。完整分析如下：

一、核心确认：两条通路的本质差别

Tokenizer 通路（全部现有 RAG）：信息必须 → 文本 → tokenizer → embedding → 从第一层开始走完整条计算链。它给模型的是"刺激"（像让人读一份资料）。

原生内部空间通路（我们）：信息直接以 KV/向量/记忆层条目的形式进入中间层——它给模型的是"状态"（像你直接想起一件事，而不是去读它）。

而且机理研究给了这条通路一个精确的定位：参数化注入集中作用于深层 FFN，提供的是"高层语义引导"——这正是你说的"直觉"的物理对应物。另一个重要佐证：prompt 通路记忆方法（Mem0/ExpeL 等）被证明"无法从根本上提升策略的决策能力" ——文本通路有能力天花板，这是原生通路存在的根本理由。

二、我们的优点（计分卡上赢的项）

延迟低（不重读）、长上下文可扩展、深层整合强、知识冲突下忠实度更强、检索噪声鲁棒性更强。另有两项是我们 v2.0 零梯度栈带来的独有优势，连 P-RAG 原版都不具备：每块存储成本比 per-document LoRA 低 1–2 个数量级（P-RAG 的 LoRA 要 6.7MB/文档，900 文档 6GB；我们的 KV/ICV/记忆层条目是 KB–MB 级）；训练/超参敏感性天然规避（没有训练过程）。还有一条意外收获：研究证明超网生成的权重（DyP-RAG）编码鲁棒知识是失败的 ——这反过来印证了我们抛弃 LoRA/超网、走零梯度路线的正确性。

三、可能性问题清单（诚实列出，共五条，全部有对策）

1. 细粒度保真有损 → 双形态兜底（高精度需求回退原文；PT-RAG 证据证明"结合"才是最优解，支持我们的双通道设计）；
2. 可解释性低 → markdown 源代码形态 + 归因监测头 + 执行溯源审计；
3. checkpoint 绑定、跨模型迁移差 → 源代码重编译跨代迁移（双形态的根本价值）；
4. 热切换的系统支持缺失（论文明确警告：现有 serving 系统下，热交换延迟会抵消理论加速）→ 这是 Runtime 的工程红线：注入中间件必须把切换成本压到毫秒级（llama.cpp slot 保存 1.4ms 已证明可行）；
5. 注入即攻击面（最严重的一条）：向量注入可以绕过一切 prompt 过滤——sleeper memory poisoning 已在 GPT-5.4/5.5、Gemini-3.1、Claude Sonnet 4.6、Kimi K2.6、DeepSeek V4-Pro 上实测成功 ；且"被污染的潜空间能逃过表层检测" 。对策已就位且需强化：块签名 + draft 区隔离 + CA1 巩固门 + MemSAD 式异常检测。这条红线决定了：我们的原生通路越强大，权限与审计就必须越严格——这不是可选项。

分析完成（文档 v2.3 §27 已落盘）。四个学科的交叉验证产生了六个直接改变我们训练方案的发现，按学科报告如下：

一、计算机科学：三个立即可用的训练技术

1. T3 奖励升级：TIAR 取代静态三元奖励。 新研究（2605.25850）发现 TruthRL 的三元奖励（+1/0/−1）实际上隐含了一个固定的 0.5 拒答阈值——无视题目难度。TIAR 利用 GRPO 天然的多条采样轨迹计算经验正确率 p̂，动态调整优势权重，在 AbstentionBench 31 个数据集的 17 个上超过静态基线且保住准确率 。我们的"承认空白→回想"行为塑形直接改用这个机制——GRPO 的组内轨迹分布本身就是免费的置信度估计器。
2. HRL indexer 的训练有整套 MoE 现成教案：教师路由蒸馏（TGR-MoE：冻结主干上训练轻量教师路由器，再用 KL 蒸馏给学生——正是我们 DSA 式 warmup 的通用版 ）；辅助损失梯度必须隔离——只允许流进路由器、禁止污染主干 ；StableMoE 的"蒸馏出稳定路由后冻结"。
3. T3 阶段的路由稳定性是已知雷区：多篇 2025–2026 论文发现 MoE 在 RL 下路由波动被奖励稀疏性放大，需要序列级重要性裁剪（GSPO）、路由预算（Ring-lite）、路由位移感知更新（RSPO）。我们的 HRL 路由器在 GRPO 阶段同样面临——已加入"相邻策略块选择重叠度约束 + ε 退火"。

二、神经工程（BCI）：KAL 探针的" calibration 制度"有了成熟先例

KAL 探针在数学上和脑机接口解码器是同一种东西（从神经信号读出意义的线性模型）。BCI 领域三十年的核心教训恰好回答了我们"探针漂移怎么办"：神经信号会漂移，所以解码器需要定期重校准，且闭环系统要监控"机器适应人"和"人适应机器"的双向漂移 。映射到我们的系统：T2 之后的定期探针重校准制度（每 N 次睡眠固化后重训探针）+ 路由器-模型共漂移监控——这把我们开放问题清单里的一条从"待研究"变成了"有现成规程"。

三、神经科学：路径学习的完整生物学蓝图（三因子学习规则）

奖励调制 STDP 的研究给出了路径强化的精确机制 ：Hebbian 共激活（走过）+ 资格痕迹（临时标记）+ 延迟多巴胺门控（回合末奖励）——而且乙酰胆碱先把旧路径压向抑制（遗忘旧奖励位置），多巴胺再把新关联逆转为增强（学会新位置）。映射严丝合缝：

- 我们的轨迹日志 = 资格痕迹（记录哪些块共激活，回合结束时奖励才施加——生物就是这么解决"奖励迟到"的）；
- 三元奖励 = 多巴胺门控；
- 错误路径的 ACh 式衰减 = 消退机制。

四、认知科学：两个直接升级睡眠固化器的发现

1. 提取练习效应：主动回忆比重学多记 50%（Roediger & Karpicke）；间隔重复效应量 d=0.46、相对集中学习最高提升 200% ；且"合意困难"（略有难度的提取）效果最好。修正我们的睡眠固化器：回放不该是"重新编码一遍"（相当于重读），而应是"间隔提取练习"——按衰减预测，在块快被遗忘的扩展间隔上以检索形式重激活它（让模型试着回忆再核对），回放难度本身作为固化强度信号；
2. 反馈的非对称效应（N=518 大样本）：反馈改善校准和策略，但不改变敏感度 ；另一项元认知训练研究证明"预测+反馈"循环能同时改善校准和下游决策，而只有预测没有反馈无效 。两个设计推论：① KAL 训练提升的是"边界使用策略"（何时拒答/回想），探针敏感度取决于数据和表征——两者要分开评估，别指望 RL 能把弱探针练好；② KAL 训练数据必须包含显式的"预测-反馈"循环。顺带一个漂亮的对应：认知科学里"认知卸载"（把记忆外包给工具）的决策研究 ，在工程学上就是我们的 recall 机制——它的训练原则可以直接照搬。
