| # | 需求（原始表述提炼） | 机制 | 关键证据 | 状态 |
|---|---|---|---|---|
| R1 | 用 LoRA/外部权重块给模型接入知识与记忆，而非 markdown 外挂 | 程序性块=LoRA、陈述性块=KV prefix；双形态（markdown=源代码，内部表示=编译产物） | S-LoRA 分页、ICAE 压缩、vLLM 动态 LoRA | 设计冻结，待实验 |

## 2. 总体策略

**验证阶段不改模型**（probe 只读感知）→ **初步集成**（外部回路改变模型行为）→ **深度集成**（接口内化）。每个阶段有独立的"退出标准"，不达标不进下一阶段——避免在沙地上盖楼。

## 3. 实验底座：Qwen3.5 评估结论

**推荐，但需带两个对照与三个注意点。**

- 家族事实：0.8B/2B/4B/9B/27B dense + MoE 系列；Gated DeltaNet : 全注意力 = 3:1；原生 262K 上下文。
- **主力 Qwen3.5-9B**：单卡（24–48GB）可做 LoRA 微调 + 探针实验；9B 规模足以产生可信的知识空白现象（0.8B–4B 本身知识太少，"空白"无处不在，信号无区分度）。
- **对照 Qwen3-8B**（全注意力）：分离"混合架构效应"与"记忆系统效应"；全注意力层上 KV 注入无限制，工具链最成熟，作为安全退路。
- 注意点：① GDN 层无 KV cache，KV 注入仅适用于 1/4 全注意力层（Block Spec 已加"载体适用性"约束）；② GDN 层 LoRA 工具链较新，先在全注意力层和 FFN 上挂 LoRA；③ 冻结 vision tower，纯文本实验。

## 4. 分阶段路线图

### Phase 0 — 基础设施（2–4 周）

- 推理栈：vLLM（ serving + 动态 LoRA）+ HF Transformers（hooks 捕获 hidden state，用于探针训练）双栈并行；
- 存储：SQLite（页表/元数据）+ 向量库（route_key）+ 文件存储（块载荷）；
- 空壳苏醒序列：实现"按 priority 清单顺序加载 LoRA"的演示，验证加载时延；
- **退出标准**：一条"提问→捕获 hidden state→落盘"的端到端管线跑通。

### Phase 1 — 知识空白探针（1–2 月，最高优先级）

- 数据集构建：模型**已知**事实集（训练截止前的高频知识，模型能答对）vs **未知**集（截止后实体、合成虚构实体、极低频长尾）；各数千条，覆盖多个领域；
- 方法：SAPLMA 式逐层线性探针（每层一个 logistic 分类器，输入 hidden state，输出"知道/不知道"）；基线：token 概率/熵（FLARE 式）、自报置信度（verbalized）；
- 指标：AUROC、ECE 校准；重点看**中间层**探针（文献显示信号最强）；
- 附加实验：探针在"被诱导说谎/幻觉"样本上的迁移性；
- **退出标准**：中间层探针 AUROC ≥ 0.8 且显著优于两个基线。若失败 → 回退纯输出分布信号方案，重估后续设计。

### Phase 2 — 读通道（1–2 月）

- 页表 + 路由器 v1（embedding top-k 检索，暂不学习）；
- 知识块注入：LoRA（全注意力层+FFN）与 KV prefix（全注意力层）双载体；先人工构造几十个知识块（某领域知识、某任务套路）；
- 触发回路：Phase 1 探针触发"回想"→ 路由取块 → 注入 → 继续生成；行为对比：注入前后该领域的回答准确率、幻觉率；
- 延迟测量：按思考段切换 LoRA 的开销（vLLM 动态加载 + PCIe 传输实测）；简化版三级缓存（L0 常驻 / L1 内存 / L2 磁盘）；
- **退出标准**：注入知识块后目标领域准确率显著提升、空白场景幻觉率下降、单段切换开销 < 思考段生成时间的 20%。

### Phase 3 — 写通道与固化（1–2 月）

- 记录器：空白事件 / 用户纠正 / 成功轨迹 → W0 日志（文本 + 激活快照）；
- 睡眠编译器：日志 → 摘要/结构化 → 蒸馏为 LoRA（梯度法）或压缩 KV；双形态一致性验证（编译产物 vs 源代码回答一致性）；
- 权限与验证门：draft→固化需通过校验集回归测试；签名与回滚；
- **退出标准**：一次"遇到新知识 → 记录 → 睡眠固化 → 次日无文本提示下直接答对"的完整闭环演示。

### Phase 4 — 闭环与进化（持续）

- RL 路由器（GRPO，奖励=任务结果 + 空白处理质量）；联想路由（图随机游走 + ε-greedy）；
- 完整苏醒序列（含人格块 v1：persona vector 提取自对比数据）；
- 归因评测：块使用率、干预贡献度、遗忘曲线；
- 长期运行实验：数周连续运行，观测记忆增长、冲突仲裁、偏差回路。

## 6. 风险登记册

| 风险 | 等级 | 缓解 |
|---|---|---|
| 探针信号弱/不可迁移 | 中 | Phase 1 设明确退出标准；基线对比先行 |
| GDN 层注入工具链不成熟 | 中 | 先用全注意力层；保留 Qwen3-8B 退路 |
| 知识块注入干扰通用能力 | 中 | 每次固化跑通用能力回归集；LoRA 秩保守 |
| 闭环自我强化偏差 | 高 | 外部评测集定期"记忆体检"；探索率下限 |
| 记忆投毒（多用户场景） | 高 | 签名 + 权限分级 + draft 隔离 |
| 归因评测无现成方法 | 中 | Phase 4 自研，作为论文级贡献点 |

## 7. 未来统一架构规划（DKB-native）

| 阶段 | 时间尺度 | 内容 |
|---|---|---|
| 近期（本计划） | 0–6 月 | probe 外挂 + 外部页表 + 双通道注入，全部在现有模型上 |
| 中期 | 6–18 月 | 接口 token 内化（训练模型自主发路由调用）；页表条目作为控制 token；GDN 递归状态作为可读写工作记忆寄存器；反思 token 蒸馏 |
| 远期 | 18 月+ | 可微页表层（地址转换进模型）；多时间尺度固化通道（CMS 式）；受控自修改子层（权限沙箱内）；路由预测器/预取器硬件化（FPGA/边缘侧确定性预取，与嵌入式平台协同） |

**中期开始的关键转向**：从"外部系统替模型管理记忆"转向"模型学会管理自己的记忆"——训练手段已明确（结果奖励 RL + 外部信号蒸馏），届时 Phase 1 的探针从"外部检测器"转变为"内在自我感知"的监督信号来源。
