# TAIS Obsidian：KAL 元认知神经科学承重文献（2026-07-26 核实）

> 专注 KAL 分层（L1 P(IK) 三态 + L2 情感 + L3 冲突 + ITI）的**神经科学侧**承重。与 self-evolution 文献表（LLM 侧探针/框架）互补。详细笔记落盘于 `article_ref/05b_metacognition_neuroscience.md`。所有来源已 Tavily 联网核实存在性。

## 核心已核实来源（✅）
- **Fleming 2024 Annu.Rev.Psychol. 75:241-268** (DOI:10.1146/annurev-psych-022423-032425) — confidence 亚个人/个人层桥接；元认知判断推断性、可与表现背离 → 探针读中层表征非自报。
- **Fleming et al. 2014 Brain 137:1483** / Miyamoto 2017/2018 Neuron — rlPFC(BA10/46) 损伤损害元认知**不损一阶** → L1 头与主干可分离。
- **Morales/Lau/Fleming 2018 J.Neurosci 38:3534** + Nelson&Narens 1990 — **监测/控制神经基质部分分离** → sense/inject 分置红线直接依据。
- **Koriat 1993 Psych.Rev 100:609** accessibility model — FOK 基于提取可及性非直接读存储；"监测跟随提取" → P(IK)"不确定"态蓝本；空白检测应后验（生成中 sense）。
- **Schnyer 2004 Neuropsychologia 42:957** — 内侧PFC损伤损 FOK 不损 confidence → 知道/不确定/空白三态有神经分离。
- **Schultz/Dayan/Montague 1997 Science 275:1593** — DA 编码 signed RPE（惊讶检测器非奖励检测器）→ 知识空白形式化模板（预测-实际差）。
- **Botvinick 2001 Psych.Rev 108:624** + **Shenhav 2013 Neuron 79:217 (EVC)** — ACC 冲突监测+控制期望价值 → L3 冲突检测蓝本；ITI 干预门=控制通道。
- **Hayden 2011 J.Neurosci 31:4178** — dACC 编码 **unsigned surprise**（非 signed RPE 非 conflict）⚠️ → L3 数学形式争议，与冲突理论并存，**T1 需消融 conflict vs unsigned-surprise**。
- **Maniscalco & Lau 2012 Consc.Cogn 21:422 (meta-d')** — Type-2 SDT，M-ratio=meta-d'/d' 量化元认知效率 → **L1 最佳数学形式**；KAL 评测升级（meta-d'/M-ratio/AURC/TCE，不止 AUROC）。
- **Shea & Frith 2019 TICS 23:560 (GWT需元认知)** — 广播表征需附 confidence → 块载荷带置信度元数据；功能层补充非数学形式。
- **Brown/Lau/LeDoux 2019 TICS 23:754 (HOT)** ⚠️ — 概念参考，主要解释意识，不迁数学形式（守诚实红线不主张意识）。
- **McGaugh 2000 Science 287:248 / 2004 Annu.Rev.Neurosci 27:1 (DOI:10.1146/annurev.neuro.27.070203.144157)** — 杏仁核(BLA)经 arousal 调制海马-皮层固化强度，**只调优先级不存内容** → L2 arousal 接写显著性/CA1固化门控直接依据。

## 三条设计启示
1. **L1 = Bayesian/SDT 形式 + 三态**（非二值 confidence），校准用 meta-d'/M-ratio。
2. **L2 arousal/valence 功能不对称**：arousal→固化门控（McGaugh），valence→检索偏向，W[d,2] 两维接不同下游。
3. **L3 保留 conflict 与 unsigned-surprise 两候选形式**做 T1 消融（dACC 功能存争议）。

## 等级标注
- 🟢 已确立：上述除 Hayden unsigned-surprise / HOT 外全部。
- 🟡 推测·新兴：Hayden 2011 unsigned surprise（单研究，与 Botvinick 并存）；valence 检索机制。
- 全部为功能性类比，不构成"LLM 有这些神经机制/意识"主张。
