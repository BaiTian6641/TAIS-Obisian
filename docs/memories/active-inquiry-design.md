# 主动求知闭环架构设计（2026-07-28，docs/TAIS_Obsidian_主动求知闭环_架构设计文档.md v0.1）

回答核心问题：元认知检测空白→主动发起学习→交叉验证→强化/修正（修正 vs 加强）。文献依据 verified-literature-active-inquiry-loop.md。

## 一句话架构
KAL P(IK) 判"不知道"+HRL 未命中 → **可学习区(RPL/LP)触发求知**（HRL 路由四选一 AskQuestion/CallTool/Decline/DirectAnswer）→ 新证据**交叉验证**（多源+自洽+外部锚，**绝不裸自我修正**）→ **信任度加权**写知识块（Jeffrey/精度加权，累积不覆盖）→ 睡眠 CA1 门按**先验一致性调速固化**（一致快/冲突慢+校验）→ **三元奖励 RL**（答对+1/幻觉−1/abstain 0~0.3）。修正高置信错误优先，加强高置信正确。

## 关键设计决策（每条文献出处见设计文档）
1. **触发点=可学习区（RPL/LP）非完全空白**（反直觉）：priority = EPIG×LP×(1−P(IK))，避开太易/太难区。完全空白区学习成本过高。
2. **求知动作四选一**（HRL 路由，arXiv:2511.08798）：AskQuestion/CallTool/Decline/DirectAnswer。先 SFT 教拒答再上 RL（2601.20126）。
3. **绝不裸自我修正**（2310.01798 决定性，被引540）：无外部锚的内在自我修正退化。修正必须检索证据/用户反馈/校验集门控。
4. **修正优先级=置信×错误乘积**（Hypercorrection）：高置信错误纠正后记得最牢→优先纠 P(IK) 高但事实错的块。
5. **CA1 门按先验一致性调速**（McClelland 2013）：一致→快固化（同化小 KL 并入）；冲突→慢通道+校验（顺应大 KL 新建块）。Shannon 惊讶 vs KL 修正量可分离。
6. **累积不覆盖抗坍缩**（2404.01413）：知识块库版本化累积，与设计红线互证。
7. **三元奖励**（TruthRL 2509.25760）：correct+1/hallucinate−1/abstain 窗口0~0.3。RL 不诱发新能力只锐化——新知识先注入再 RL 加固，顺序不能反。

## 与推理循环整合
求知嵌进 reasoning_loop tick：certainty 低+未命中→求知分支（非硬答）→验证→写入→流形位移到新知识点→重评估 P(IK)。空间推理验证=流形几何一致性（与先验冲突=位移异常/孤立点）。

## TAIS 独创点（无先例，需 pilot 外推）
- P(IK) 门控持续学习（CL 多为数据流触发）
- P(IK)×EPIG×LP 三信号耦合公式
- Hypercorrection 在知识块上的操作化
- 顺应/同化块级 KL 阈值

## 三红线
①防错误固化=绝不裸自我修正+累积存储；②防过度自信=三元奖励+真值锚 P(IK)；③验证成本=求知目标按可学习性×EPIG 排序。
