# 知识内化训练阶段1：合成 K-依赖教学样本 + 教学式 SFT pilot（2026-07-29）

## 产出
`scripts/build_teaching_data.py`（221 行）+ `scripts/teaching_sft.py`（290 行）+ `tests/test_teaching_data.py`（204 行，11 项全绿）+ checkpoint `checkpoints/pilot_0p1b_gdn2_10k_teaching/`。子代理实现，我验收（report 数据确认+独立重跑+全量 296 绿）。基座 GDN-2 10k，RTX 4070 跑微调（双卡分工）。

## 数据管线（K-依赖是灵魂）
500 条样本（fact 200/chain 150/consist 150）。程序化虚构实体（对齐 diverse_truth_data 经验）——**虚构实体 350 个在 val 语料出现 0 个（先验不存在，去掉 K 只能猜）**。三类：①事实内化（K 虚构事实→Q 依赖 K→A）；②知识链条内化（A→B→C 链式推理）；③一致/矛盾区分（退联检验，accept 432/reject 68）。SFT 格式："{K}\nQuestion:{Q}\nAnswer:{A}"，label mask 只算 Answer（只学答不学背）。

## SFT 结果（300 步，bf16+AdamW lr1e-4，micro16×seq192，4.54GB）
loss 6.27→收敛（first50 1.227→last50 ~0）。

## ⭐ 内化评估（真实跑出，n_dep=66）
| 指标 | SFT 前 | SFT 后 |
|---|---|---|
| 有 K 答对率 | 0.015 | **1.000** |
| 无 K 答对率 | 0.000 | 0.242 |
| **内化差值（有K−无K）** | 0.015 | **0.758** |
| 一致 K 内化率 | 0.000 | **1.000** |
| 矛盾 K 内化率 | 0.000 | **0.000** |
| **退联检验差值** | 0.000 | **1.000** |

**判据全达成**：①有 K≫无 K（1.0 vs 0.242=用上 K 非凭先验）；②SFT 后内化差显著（0.015→0.758 教学有效）；③一致全内化/矛盾全拒（退联检验完美，模型学会区分真伪）。

## 诚实边界
SFT 后无 K 答对率升 0.242——部分评估题实体在 train 出现过（同类句式轻微先验）；有 K 1.0 远高于之，内化判据仍显著。后续可用完全 held-out 实体做更严 OOD 评估。
