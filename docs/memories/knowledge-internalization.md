# 知识内化训练设计（2026-07-29，docs/TAIS_Obsidian_知识内化训练_分析与设计.md v0.1）

回答：①如何训练模型推理时知识内化（用户答"不知道"后学习/用户给知识链条退联检验学习，新知识**实时可用**）；②如何正确训练此行为。

## 核心架构：双速通道（CLS 双系统）
- **运行时（快，秒级）**：新证据→交叉验证→知识块（steering 有界写入 W1–W2）→**实时可用**（推理循环 HRL 检索命中→kernel.inject 注入→同对话后续即可用，无需等睡眠固化）。
- **睡眠期（慢，离线）**：知识块→CA1 门（先验一致性调速：一致快/冲突慢+校验）→间隔提取练习→固化入主干（W3+/W4 Muon 同优化器+谱修剪）→长期记忆。

## 三训练目标（部件已备，需训练行为）
1. **内化行为**（In-Context Learning to Learn）：教学式 SFT——样本{知识链 K, 问题 Q, 答案 A(K)}，**Q 必须 K-依赖**（去掉 K 答错），防"凭先验答忽略 K"。退联检验训练：一致知识→内化 vs 矛盾/错误→拒/标分歧。
2. **元认知门控**（知道何时该学）：KAL P(IK) 三态监督——用户给的新知识若是空白（P(IK)低）→应学；已知→不必重学；错误/冲突不可信→应拒（CrossVerifier 判真伪，绝不裸自我修正）。
3. **实时可用性**：检索-内化联合训练——新写入知识块应被后续 query 的 route_candidates 命中（检索监督）+注入后答对（端到端）。梯度隔离红线（辅助损失只进 indexer）。

## 三阶段管线
①SFT 教行为（教学式+退联检验+KAL 监督，数据 cosmopedia/finemath/squad_v2/SelfAware）→②运行时闭环（求知执行器 CrossVerifier 验证+KnowledgeBlockWriter 写入+HRL 命中注入实时可用）→③睡眠固化（CA1 门调速+三元奖励 RL）。

## 四风险防御
①凭先验答（K-依赖样本+检索监督+说-做一致性审计）；②盲目内化错误知识（CrossVerifier+信任度加权+冲突保留双方+睡眠验证门，绝不裸自我修正）；③实时与固化不一致（CA1 调速+累积不覆盖+markdown 审计回滚）；④内化泛化（多样化数据+OOD 评估）。

## 诚实边界
运行时块未固化（持久性/容量受限）；退联检验验证是概率的；K-依赖样本构造难需自动化；内化-检索-注入端到端训练未验证（pilot 需消融）。
