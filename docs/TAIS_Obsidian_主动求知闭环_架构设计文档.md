# TAIS Obsidian 主动求知闭环 · 架构设计文档

> **版本 v0.1 · 2026-07-28**。回答核心问题：**当模型元认知检测到知识空白（KAL P(IK) 低、"不知道"/"不确定"信号被采样、海马 HRL 检索未命中）时，模型应如何主动发起学习行为（请求解释/查阅文档/网络搜索自我学习），并确保学到的内容经得起交叉验证与强化学习（修正错误观念 vs 加强正确观念），结合上下文推理与空间推理保证学习过程与结果。**
>
> 文献依据：`/memories/repo/verified-literature-active-inquiry-loop.md`（2026-07-28 Tavily 联网交叉验证，CS/神经/认知三视角，编号逐条核实）。
> 证据分级：**[已确立]**（同行评审/已核实文献）｜**[推测/独创]**（理论外推或 TAIS 首创，无先例）。

## 0. 一句话架构

**KAL 元认知探针判"我不知道"（且海马检索未命中）→ 在"可学习区"（RPL/LP）触发求知动作（提问/查文档/联网搜索，HRL 路由四选一）→ 检索/交互得来的新证据经交叉验证（多源一致 + 外部锚，绝不裸自我修正）→ 信任度加权（Jeffrey 条件化/精度加权）写入知识块（运行时只读快写，累积不覆盖）→ 睡眠期 CA1 门按"与先验一致性"调速固化（一致快/冲突慢+校验），三元奖励 RL 强化（答对/拒答/幻觉）——修正高置信错误优先，加强高置信正确。** 上下文推理（推理循环 tick 动力学）与空间推理（思考流形导航）贯穿求知与验证全程。

## 1. 触发：何时发起学习？（元认知 → 求知动作）

### 1.1 触发信号（三层，全部已有 TAIS 部件）

| 信号 | 部件 | 语义 | 出处 |
|---|---|---|---|
| **P(IK) 低** | KAL L1 三态探针 | 元认知判"不知道/不确定"（真值锚，非语言建模置信度——KAL 负结果已证 logprob≠真假） | 已有（AUROC 0.945/真值锚微调） |
| **HRL 检索未命中** | HRL Indexer + CA3 PPR | 海马在知识块库/情景轨迹中未检索到相关知识 | 已有（route_candidates + associative_recall） |
| **L3 冲突** | KAL L3 冲突头 | 检测到与既有知识冲突（修正候选） | 已有（三态 conflict） |

**[推测/独创] LLM 的元认知门控持续学习**：文献检索证实"由模型自身 P(IK) 自主决定何时发起一次学习"无成熟先例（现有持续学习多为数据流触发）——**这是 TAIS 的核心独创点**：P(IK) 不只是监测信号，而是**学习行为的门控信号**。

### 1.2 触发点设定：可学习区（RPL/LP），非"完全空白"⭐

**[已确立，反直觉、极重要]** 认知科学证据（Metcalfe RPL + Oudeyer/Schmidhuber Learning Progress，神经 rlPFC/纹状体/ACC 互证）：

> **求知欲最强的不是"完全不知道"（完全空白），而是"中等不确定/差一点就知道"（Region of Proximal Learning / TOT 舌尖态）**。完全空白区学习成本过高；已掌握区无可学。**好奇心 ∝ 学习进展（learning progress，预测误差下降率），非 ∝ 无知程度**。

**设计决策（[推测/独创]）**：求知优先级 = 三信号联合（各自成熟、耦合公式 TAIS 自拟）：
```
priority(q) = EPIG(q) × LP(q) × (1 − P(IK)(q))
  EPIG(q)：减未来预测不确定性的期望信息增益（"学哪个值"——bickfordsmith23a，优于 BALD）
  LP(q)：学习进展（"哪个学得进"——Oudeyer/Schmidhuber；避开太易/太难区）
  (1−P(IK))：无知度（KAL 探针直读）
```
- **求知目标排序**：优先"中等不确定 × 高学习进展 × 高 EPIG"的区；**完全空白区（P(IK) 极低且无可达锚）与已掌握区（P(IK) 高）都降权**——把有限的检索/提问/睡眠固化预算花在刀刃上（设计约束③验证成本）。

### 1.3 求知动作空间（HRL 路由四选一）⭐

**[已确立]** 主动澄清 RL（SpeakRL arXiv:2512.13159 / Structured-Uncertainty-GRPO arXiv:2511.08798）已证明"何时问/何时查"可经 RLVR 训练，动作空间成熟。

**设计决策**：HRL 路由头动作空间 = **四选一**（对齐 arXiv:2511.08798）：
```
{ AskQuestion（请求用户解释更多）
, CallTool（查文档/联网搜索自我学习）
, Decline（诚实拒答——"该部分记忆暂不可用"，对齐诚实降级红线）
, DirectAnswer（直接回答——P(IK) 高）
}
```
- **上下文推理**：路由决策在推理循环 tick（`reasoning_loop.py`）中由 KAL certainty 门控——certainty 低且未命中→进入求知分支而非硬答。
- **先 SFT 教拒答再上 RL**（[已确立] arXiv:2601.20126）：两阶段——先用真值锚 SFT 教模型"会拒答/会提问"，再 RLVR 加固（正合我们真值锚微调已先行）。

## 2. 求知：如何学习？（提问 / 查文档 / 联网搜索）

### 2.1 三条求知通道

| 通道 | 机制 | 文献依据 | TAIS 映射 |
|---|---|---|---|
| **提问**（请求解释） | 主动澄清，把"解释"当新证据输入 | Ask-or-Assume 2603.26233；Reasoning-While-Asking 2601.22139 | 生成 `<|ask|>` 显式 token，用户回答进上下文 |
| **查文档** | 检索内部知识块库/文档 | Self-RAG 2310.11511；UAR 2406.12534 | HRL 检索（知识-aware + self-aware 两路信号） |
| **联网搜索** | 调网络搜索工具获取外部证据 | Toolformer（Schick 2023）；FLARE 2305.06983 | 工具调用接口（外部证据源） |

**[已确立] UAR 双路触发**（arXiv:2406.12534）：检索触发门同时吃两路信号——**knowledge-aware**（指令事实相关性，路由层任务类型）+ **self-aware**（模型自觉不知，KAL P(IK)）。TAIS 的 HRL 检索触发应采此双路。

**[已确立] FLARE 警示**：token 概率门（FLARE logprob）应换为**真值锚 P(IK)**——KAL 负结果已证语言建模置信度≠事实真假。

### 2.2 检索有成本，计入效率预算

**[已确立]** DRAGIN / UAR"被动检索伤通用性"——求知动作必须计入效率预算（每次提问/检索/搜索都有成本）。这与 §1.2 的 priority 排序耦合：**只有 priority 足够高的求知才执行**，否则 Decline（诚实降级）。

## 3. 验证：如何确保学到的是真知识？（交叉验证）⭐⭐

**这是整个闭环的成败关键。文献给出决定性证据：**

### 3.1 绝不裸自我修正（[已确立]，决定性）

> **arXiv:2310.01798《LLM Cannot Self-Correct Reasoning Yet》（DeepMind/UIUC，ICLR 2024，被引 540）：无外部反馈的内在自我修正不仅无效且常致退化**；既往正面结果多靠 oracle label（不公平）。凡有效的自我修正（CRITIC/Reflexion/Self-Refine）**都外接了工具/环境反馈**。

**设计红线（不可妥协）**：**TAIS 闭环绝不依赖模型"自己觉得自己改对了"**——所有修正必须由外部信号门控：检索证据 / 用户反馈 / 校验集回归。这直接支撑并加固既有红线"draft→固化必须验证门"。设计原则 = **Reflexion 的记忆 + CRITIC 的工具验证 + 绝不裸自我修正**。

### 3.2 交叉验证 = 多机制叠加（[已确立]）

单一机制不足，须多机制叠加（arXiv:2505.09031）：
- **多源一致性**（检索多个独立来源比对）；
- **自洽性**（Self-Consistency arXiv:2203.11171，多路径采样多数投票）——**但警示（2310.01798）：自洽收益来自"一致性"非"正确性"，只能作辅助信号不能当真值**；
- **检索验证 / 外部知识源自验证**（Self-Verification arXiv:2212.09561，裸自验证弱，须挂外部源）。

**[推测/独创] 空间推理验证**：在思考流形上，新知识与既有知识的几何一致性可作验证信号——与先验冲突的新知识在流形上表现为"位移异常/孤立点"（CA1 门"与先验一致性"的几何读出，见 §4.2）。这是上下文推理（推理循环）与空间推理（思考流形）在验证环节的交汇。

## 4. 固化：修正观念 vs 加强观念（写入与睡眠巩固）

### 4.1 信任度加权修正（[已确立]，数学形式现成）

新证据带可信度（可能错的检索结果），**不能假设证据为真**（标准 Bayesian 条件化的理想化）。用：
- **Jeffrey 条件化**（Stanford Enc. Philosophy）：证据带概率 P(E)∈(0,1) 直接进入更新，P(E) 低则弱更新；
- **精度加权预测误差**（Predictive Processing）：`Δμ = [π_s/(π_p+π_s)]·(x−μ_p)`——信源可信度→π_s（证据精度），块现有置信度→π_p（先验精度）。证据精度高（可信源/多源一致）则大权，先验精度高（既有强知识）则抗改；
- **BEWA**（arXiv:2506.16015）：信源可信度加权 + 时间衰减 + 显式矛盾处理（非覆盖）。

**设计决策**：知识块带 `source_credibility` 元数据，修正幅度 ∝ 信源权重 × 时间衰减；矛盾经"概率矛盾模型"处理而非覆盖（对齐冲突不静默覆盖红线）。

### 4.2 修正 vs 加强的仲裁（[已确立]，Hypercorrection + 先验一致性）⭐

**(a) 修正优先级（Hypercorrection effect，Metcalfe）**：
> **高置信错误被纠正后记得最牢**（vs 低置信错误）。机制=高置信错误引发更强惊讶/注意→增强编码（神经：ACC 冲突监测 + dlPFC 抑制旧响应 + TPJ 外部真值锚——与 TAIS L3 冲突检测 + erase gate 抑制旧关联 + 检索外部锚三件套同构）。

**设计决策**：修正优先级排序 = **置信度 × 错误度乘积最高者优先**——优先纠正那些 **P(IK) 高但事实错误**的块（最危险），而非低置信块（[推测/独创]：心理学结论在知识块上的操作化，无直接文献，需自标定）。

**(b) 固化速度（McClelland 2013 修正，CLS）**：
> **与先验一致的新知识可快速并入（同化，低风险）；与先验冲突的必须慢速+反复校验（顺应，高风险）**——单次错误经验因与先验冲突被天然挡在慢通道。

**设计决策**：**CA1 巩固门以"与既有知识的一致性"作固化速度调控变量**：
- 一致 → 快固化（并入既有块，小 KL 更新）；
- 冲突 → 留 draft 区 + 版本仲裁 + 慢速 + 校验集回归（大 KL 新建块）。
- **[推测/独创] 顺应 vs 同化的块级 KL 仲裁**：用先验-后验 KL 散度阈值判定"新建块（大 KL，顺应）vs 并入主干（小 KL，同化）"——O'Reilly 瞳孔研究证 Shannon 信息（惊讶，后顶叶）与 KL 散度（信念修正量，ACC）可分离，TAIS 应分别测 (a) 预测误差（触发检测）与 (b) 先验-后验 KL（决定修正强度）。

### 4.3 防错误固化（[已确立]，工程解）⭐

> **arXiv:2404.01413《Is model collapse inevitable?》：数据累积（不替换）时测试误差有有限上界，可避免坍缩**；替换数据则误差随迭代线性增长。对照：MAD（2307.01850）+ Nature 631:755（2024）证递归生成数据训练致坍缩。

**设计决策（与既有红线完全互证）**：
- **知识块库"累积不覆盖"**（页表版本化保留旧块）——累积式存储在理论上抗坍缩，与设计"冲突不静默覆盖、版本号+时间戳+置信度三路仲裁"红线**完全一致**；
- **睡眠固化训练数据 = 真实锚 + 有限合成**（合成占比有上限，掺足量 ground-truth，保留真实分布尾部）——支撑"markdown 源代码形态=最终审计/回滚依据"红线。

## 5. 强化：经得起 RL 的观念（奖励设计）

### 5.1 三元奖励（[已确立]，直接可用）⭐

> **TruthRL（arXiv:2509.25760）：三元奖励 {correct +1 / abstain / hallucinate −1}，减幻觉 28.9%**——二元 RLVR 把"拒答"与"答错"混为一谈，反而惩罚校准的"我不知道"。

**设计决策**：睡眠期 RL 用**三元而非二元奖励**：
```
reward = +1（答对=学到真知识/加强正确观念）
         −1（幻觉=学到错误知识/修正失败）
         r_abs（拒答/abstain，窗口 ≈0~0.3，arXiv:2601.20126——不过罚否则模型宁可幻觉，不过奖否则过度拒答）
```
- **先 SFT 教拒答再上 RL**（两阶段，正合真值锚微调已先行）；
- **RLVR 边界警示**：RL 不诱发基座新能力，只锐化已有分布——**全新知识须先经知识块/SFT 注入，再 RL 加固，顺序不能反**。

### 5.2 修正 vs 加强的 RL 信号

- **加强正确观念**：检索/提问验证为真 + 答对 → +1 奖励 → 睡眠固化加强；
- **修正错误观念**：外部锚证伪 + 修正后答对 → 对"修正行为"给奖（对 Hypercorrection 高置信错误的修正给更高奖，因其收益最大）；修正后仍错 → −1（幻觉）。
- **[推测/独创]** 把"学到东西"本身当内在奖励（好奇心=奖赏，纹状体 BOLD 证据 Gruber 2014/Kang 2009）——Learning Progress 作内在奖励项，与外在三元奖励叠加。

## 6. 与思考流形/推理循环的整合（上下文推理 × 空间推理）

求知闭环不是外挂流程，而是嵌进第二阶段已贯通的推理循环（`reasoning_loop.py` §1.3 tick 动力学）：

```
思考 tick（推理循环）：
  GDN 状态 → glimpse → HRL 提议 → KAL certainty
    ├─ certainty 高（P(IK) 高）→ 流形位移 → bridge.tick 写 PM → 输出（DirectAnswer）
    └─ certainty 低（P(IK) 低）+ HRL 未命中
        → <|recall|> 显式审计（空白显形化红线）
        → 求知分支（HRL 路由四选一：AskQuestion/CallTool/Decline）
            → 检索/交互得新证据 → 交叉验证（多源+自洽+外部锚，绝不裸自我修正）
            → 信任度加权写知识块（Jeffrey/精度加权，累积不覆盖）
            → 流形位移到"新知识点"→ bridge.tick → 重评估 P(IK)（P(IK) 升高则闭环）
  睡眠期：CA1 门按先验一致性调速固化（一致快/冲突慢+校验）→ 三元奖励 RL 强化/修正
```

- **上下文推理**：求知决策在推理循环 tick 中由 KAL/HRL 实时门控（reasoning_loop 的 certainty 分支扩展）。
- **空间推理**：求知 = 思考流形上向"知识空白区"的导航；新知识的写入 = 流形上新增可寻址节点（对齐"知识块作流形可寻址节点"独创外推）；验证 = 流形几何一致性（与先验冲突=位移异常）。
- **审计**：`<|recall|>`（空白）+ `<|ask|>`（求知动作）显式出现在 CoT——对齐"必须显式出现在 CoT 中"红线，可解释性前端渲染求知轨迹。

## 7. 设计约束（三条红线，来自文献交叉验证总判定）

1. **防错误固化 = 绝不裸自我修正 + 累积式存储**：所有修正经检索证据/用户反馈/校验集门控（2310.01798）；知识块库累积不覆盖（2404.01413）；单次冲突经验走慢通道（CA1 门按先验一致性调速，McClelland 2013）。
2. **防过度自信 = 三元奖励 + 真值锚 P(IK)**：RLHF 致过度自信（Barkan/Kapoor）；P(IK) 必须真值锚（非 logprob）；RL 奖励区分答对/拒答/幻觉（abstain 窗口 ≈0~0.3，先 SFT 后 RL）。
3. **验证成本 = 求知目标按"可学习性 × EPIG"排序**：好奇心不是"哪里不会学哪里"（RPL：完全空白区成本过高）；优先"中等不确定 × 高学习进展 × 高 EPIG"区，避开完全空白区与已掌握区——有限求知预算花在刀刃上。

## 8. 诚实边界

1. **三信号耦合公式（P(IK)×EPIG×LP）是自拟的**：各自成熟，但单模型内耦合无先例——pilot 须消融各信号贡献，防权重失衡。
2. **Hypercorrection 在块上的操作化未验证**：置信×错误排序修正是心理学结论，LLM 知识块实现需自标定（可能高置信错误难纠正，与文献相反——须 pilot 实测）。
3. **顺应/同化的 KL 阈值需自标定**：CLS 给原则，LLM 块的"新建 vs 并入"阈值无文献值。
4. **主动求知的用户体验成本**：频繁提问/拒答伤可用性——求知频率须随 P(IK) 校准度联合调参（过度求知=过度拒答的另一形式）。
5. **联网搜索的证据质量**：网络来源可信度参差，source_credibility 的先验设定与在线更新是开放问题（BEWA 给框架，具体权重需工程标定）。
